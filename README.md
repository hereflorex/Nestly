# Nestly

A modern private conversation platform starter with web-first responsive UI.

## Run

1. Create and activate a Python virtual environment.
2. Install dependencies: `pip install -r requirements.txt`
3. Copy `.env.example` to `.env` and set a strong `SECRET_KEY`.
4. Start: `python run.py`
5. Open `http://127.0.0.1:5000`.

This starter includes landing page, authentication, account dashboard, invite-style room creation and a basic real-time room interface. It is not production-ready until security review, rate limiting, moderation workflows, media validation, migrations and deployment configuration are completed.
